# Discord 投資記錄機器人

股票／基金記帳、觀察清單、分幣別持倉估值，以及 Ollama 本地摘要。

目前版本：**0.9.5**（自行換帳號搬移資料、格式2備份與AI重新同意）。大型更新遞增次版本，小型新增、調整與修錯遞增修訂版本；歷史原編號仍可在 [更新紀錄](CHANGELOG.md) 對照。後續依 [專案規則](AGENTS.md) 拆成小任務執行並同步記錄。

本次補充Git安全設定與文件，版本維持0.9.5，無程式行為或資料庫變更，無需重啟或升級。

## 上傳 GitHub 前

根目錄 `.gitignore` 保留原有規則，排除Token、環境祕密、金鑰、資料庫與SQLite旁檔、備份／匯出／上傳／日誌目錄、Bot匯出ZIP、虛擬環境、快取與編輯器暫存。原始碼、`tests/`、README、CHANGELOG、PRIVACY、requirements及 `.env.example` 保留；範例設定只能填示意值，不可放真實憑證。

本次以暫存Git儲存庫驗證42個虛構路徑：33項正確忽略、9項正確保留；未重跑程式測試。目前專案尚非Git儲存庫，無法確認GitHub或其他儲存庫是否已追蹤敏感檔案。本機存在 `token.txt` 與 `data.db`，只檢查檔名，未讀取或修改內容。

上傳前請自行檢查 `git status --short` 與 `git diff --cached --name-only`；任意命名且位於忽略目錄外的備份、匯出及真實設定仍需人工確認。`.gitignore` 不會移除已追蹤檔案；若發現已追蹤敏感檔案，可自行使用 `git rm --cached -- 檔案名稱` 解除追蹤並保留本機檔案，再提交變更。此操作不會清除舊提交；若憑證曾上傳，仍須撤銷／更換憑證並處理遠端歷史。本次未執行加入追蹤、解除追蹤或上傳。

私訊 Bot 輸入 `!help` → **生活記帳** 直接開啟私人生活看板，再按 **＋記一筆消費** 填寫表單；`!記帳說明` 與既有文字指令保留。0.6.3依使用者要求移除 `/生活` 與 `/記帳`。

生活看板只有三個主要頁面：

- **今天**：實際本月已支出、剩餘總預算（未設定顯示「尚未設定」）、主要操作「＋記一筆消費」及最多3個啟用捷徑；不顯示其他設定或報表。切換歷史帳目月份不影響今天摘要。
- **帳目**：預設月曆，日期格只顯示日期與深淺、不顯示金額；選日後才看當日總額、完整帳目與修改入口。搜尋、清單檢視與最近再記合併於「帳目工具」；月份切換與日期操作保留。
- **更多**：需要調整資料請選「設定」；想看花費狀況請選「洞察」。只保留「設定／洞察／常用捷徑管理」三個主要入口；選單訊息和提示直接列出完整功能。

## 我想做什麼？

| 用固定方式快速記帳 | `今天 → 常用捷徑（直接點捷徑名稱）` |
| 找用途、名稱或日期範圍內的帳目 | `帳目 → 帳目工具 → 搜尋帳目` |
| 查看或修改某天的消費 | `帳目 → 月曆 → 選日期 → 選帳目` |

| 換Discord帳號搬移資料 | `私訊 Bot → !help → 生活記帳 → 更多 → 設定 → 我的資料與隱私 → 匯入我的備份` |
| 匯出或永久刪除自己的生活資料 | `更多 → 設定 → 我的資料與隱私` |
| 重新查看首次使用導覽 | `更多 → 設定 → 重新開啟新手導覽` |

| 新增、排序或停用首頁捷徑 | `更多 → 常用捷徑管理` |

想記帳看「今天」；想找、看或改帳目看「帳目」；想設定或分析看「更多」。

「帳目工具」列出搜尋帳目、清單檢視、最近再記；「設定」列出預算、固定負擔、付款來源、分類、提醒、重新開啟新手導覽、我的資料與隱私；「洞察」列出支出圖表、本週回顧、本月回顧、生活 AI、本月結帳。子功能開啟私人表單或訊息，完成後可回到原工具選單按「返回主看板」。預算、固定負擔及生活 AI 會開對應看板頁，直接按「更多」返回。分類沿用既有指令說明與文字管理。


**我的資料與隱私**：`更多 → 設定 → 我的資料與隱私` 可查看資料使用說明；匯出、匯入與刪除須在Bot私訊中操作，伺服器頻道不處理這些財務內容或附件。匯出先提醒，再傳送私人附件；空資料仍提供欄位與說明檔，檔案在記憶體產生，不留下專案匯出檔。匯出後仍需另按「確認永久刪除」，取消／逾時不刪除；UI 與 `!生活清除 yes` 共用清除規則，投資及其他使用者資料不受影響。詳細資料範圍、本地 AI、主機與 Discord 可見性限制見 [生活資料與隱私說明](PRIVACY.md)。私人回覆不等於端對端加密，請自行保護下載的匯出檔。

**自行換Discord帳號**：Discord帳號就是帳本身分。舊帳號私訊Bot，從「更多 → 設定 → 我的資料與隱私 → 匯出我的生活資料」保存新版ZIP；新帳號由同頁「匯入我的備份」上傳。預覽按資料類型列備份、略過與預計新增／套用筆數，明確確認才寫入目前帳號。取消／逾時不寫入；確認時立即交易重新去重，失敗整批回滾，完成列新增／略過／失敗數量。

備份包含消費（含撤銷狀態及已入帳固定／訂閱／分期）、自訂分類、付款來源、常用捷徑，以及本月與未來月份最後儲存的預算設定，不含歷史預算調整。只有本人有投資資料時才附股票持倉、基金交易、觀察清單、基金淨值及必要交易歷史／撤銷關聯。消費以日期、金額、用途、分類、付款來源名稱、來源類型、撤銷狀態與種類完全相同比對，不使用流水號、舊Discord ID或匯出時間；備份內重複也略過。

同名分類／付款來源沿用目前設定（含停用狀態），內建分類視為既有；同名捷徑保留目前設定，完全相同亦略過，新捷徑依備份排序接在既有項目後。目標已有任何預算時略過備份預算；否則套用仍有效的本月／未來預算。投資同股票代號／基金若目標已有持倉、交易歷史或基金淨值，整組略過，避免混合兩份持倉；新標的保留必要撤銷關聯。衝突數列為略過，原帳號資料不刪除。

格式2 ZIP 包含 UTF-8 BOM 的五份CSV（消費、分類、付款來源、捷徑、預算）、README.txt、consumptions.json、settings.json、manifest.json，有投資才附 investments.json。JSON保存原文，CSV文字有公式保護。驗證必要檔案、版本、欄位與SHA-256完整性；**不使用簽章，不能證明來源真偽**，請只使用自己保存的原始檔。格式1及更舊備份不支援，需由舊帳號重新匯出。單次8 MiB、解壓32 MiB，每種資料最多10000筆；超限拒絕、不部分匯入，記憶體處理、不解壓落地。

不搬移舊Discord ID、AI對話、AI使用紀錄、AI偏好、Token、管理者設定、其他使用者資料、固定負擔規則、提醒或新手導覽狀態。AI預設關閉；匯入成功後目前帳號AI也關閉，下一次主動使用生活／投資AI先詢問同意，確認前不讀取分析資料或呼叫模型；同意後再次選用功能才執行。取消或失敗不改AI偏好。

**無法登入舊Discord帳號且沒有相容備份時，Bot無法找回資料。** 應用程式不提供管理者查看、搜尋、代匯入、代轉移或個別還原權限；主機管理者仍可能直接讀取本機資料庫。所有財務及資料操作限定Bot私訊，伺服器只保留說明等非財務入口。Discord仍處理附件，私訊不等於端對端加密。本輪未加入每日備份、刪除帳號、管理者告警、簽章金鑰、多幣別、App帳號或外部服務。

**首次使用導覽**：全新使用者開啟生活記帳時，私人導覽卡與主看板一起提供，直接記帳不受阻擋。有消費（含撤銷）、預算、自訂付款來源、捷徑、固定負擔、分類或提醒設定者不會自動顯示；預設現金／未指定不算自訂資料。付款來源與捷徑沿用管理流程，按「返回新手導覽」回同一張卡；當月預算沿用原表單。按「先跳過／完成導覽」永久關閉自動導覽；只關閉訊息而未設定生活資料，下次仍可顯示。手動重新開啟不重設自動狀態；0.9.1起，完整生活清除也會移除導覽偏好，再次開啟視為新使用者。

**手動月結摘要**：`更多 → 洞察 → 本月結帳` 使用看板所選月份，標題為 `YYYY-MM · 月結摘要`。列已記錄總支出、總預算使用／剩餘或超支、前三大分類、依歷史名稱分組的付款來源、未指定來源筆數與金額，以及上月同期差額。本月比較截至今天的共同天數（遇短月取兩邊共同日期），歷史月比較各完整月份，卡片明列比較起訖。任一邊無紀錄顯示資料不足，無總預算顯示尚未設定；空月份仍可看已設定預算。統計沿用有效消費口徑，含有效固定項目並排除撤銷／非消費；資料多時翻頁。僅依已記錄消費統計，不代表全部實際消費。純讀取、不呼叫 AI、不建立排程或推播，全部僅本人可見。

**搜尋帳目**：`!help → 生活記帳 → 帳目 → 帳目工具 → 搜尋帳目`，同一張表單只填名稱／用途關鍵字、開始日、結束日，皆可空白但至少填一項。日期文字欄接受 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`，在共用資料層轉為 `YYYY-MM-DD`；不存在的日期、混用分隔符號、句點及未補零仍拒絕。關鍵字部分比對用途文字，例如「早餐」可找到「早餐店」；與日期條件同時套用。只填開始日查至今天，只填結束日查該日及之前的有效手動消費，兩日期包含起訖日；錯誤格式、未來日期或開始日晚於結束日會拒絕。

搜尋只列自己的有效手動消費，排除固定／訂閱／分期、撤銷及他人資料，依日期與編號由新到舊，每頁6筆。結果顯示日期、金額、分類、用途、付款來源；點選重新讀取紀錄並開既有修改表單，保留所有者、來源／分類驗證與版本衝突防護。搜尋結果與提示僅本人可見；修改後請重新搜尋查看最新結果。

**30 天智慧捷徑推薦**：只在「更多 → 常用捷徑管理 → 查看推薦」出現，不主動通知、不建立排程，也不自動修改首頁。首頁有三個啟用捷徑時，以今天往前29天至今天的有效手動消費計數；分類、啟用付款來源ID與用途完全相同才合併。排除首頁三個組合、已撤銷、非消費、固定／訂閱／分期、停用分類／來源及他人資料。候選需至少達 `max(3, 首頁最低次數 × 2)`，同分目標選首頁排序較後者。推薦卡顯示兩者次數與日期範圍。

「採用建議」只開既有捷徑修改表單，預填候選名稱、分類、來源與用途；金額保留原捷徑值，位置不變。名稱沿用30字限制，較長用途以其前30字預填名稱，完整用途保留。確認後才更新指定捷徑；忽略、返回或關閉不寫入。開表單前重新檢查推薦，儲存時沿用來源及分類驗證。

**帳目月曆**：因 Discord 中文字型欄寬不穩，月曆星期改為 ASCII 英文縮寫 `Mon Tue Wed Thu Fri Sat Sun`（Mon 到 Sun）。星期與日期共用三字元欄位、一個半形空白分隔；空白日期占三個空白，各欄起點為0、4、8、12、16、20、24。2026-09的01對應Tue、06對應Sun。只有月曆標題列改英文，日期選單保留中文星期。請重啟Bot後重新開啟面板，查看Discord桌面與手機實機畫面；本輪尚未實機驗證。`—` 表示無已記錄消費；以當月最高每日金額為基準，`░` 為不高於1/3、`▒` 為高於1/3且不高於2/3、`▓` 為高於2/3。包含有效固定支出，無效紀錄不計；「未記錄不代表沒有消費」。日期固定分「前半月（1～15 日）」與「後半月（16 日～月底）」，後半最多16項，顯示完整日期與星期。完整月份皆顯示，本月尚未到的日期沒有補入資料；未來月份不可選。選日後列當日總額及每頁6筆完整帳目，沿用單筆修改與回月曆入口；空月份可切月或快速記帳。

既有行情套件 `yfinance`／`pandas` 改在首次查價時載入，避免其載入耗時阻擋生活功能啟動；查價仍走既有背景執行緒。使用者提供的 `KeyboardInterrupt` 代表載入被中斷，尚不能判定套件損壞；本次未重裝套件，未驗證該電腦Python 3.13的實際載入耗時或即時行情。
- **常用捷徑**：今天頁依既有排序顯示最多3個啟用捷徑，點選會重新讀取本人捷徑並開確認表單；沒有捷徑時只顯示一個建立入口。完整清單與新增／修改／排序／停用移至「更多 → 常用捷徑管理」。新增與修改直接開啟同一張表單：名稱、分類下拉、付款來源下拉、用途、選填金額。使用時直接開啟預填確認表單，日期預設今天；可在表單內修改所有消費欄位，儲存才新增消費。
- **最近再記**：從「帳目 → 帳目工具 → 最近再記」進入，按消費日期與編號倒序顯示最近6筆有效手動消費，排除固定負擔及撤銷紀錄；選取後預填今天並確認才新增。原消費不會被修改。
- **停用來源處理**：捷徑與最近再記都在表單內下拉選取啟用來源；原來源停用時必須重新選擇。兩者皆可使用現金／未指定，儲存時再次驗證，選取後被停用也不能寫入。
- **回顧**：從「更多 → 洞察」選「本週回顧／本月回顧」查看規則式統計，不需AI，也不新增主動推播。本週與上週相同星期範圍比較；本月至今日與上月同日範圍比較，短月僅比較雙方共同天數並明列日期。本月含主要分類、來源分布與預算狀態；任一期無資料不計差額，完全無紀錄不推斷預算使用率為零。僅依已記錄資料統計，不代表真實消費增減。

`!help` → 投資紀錄：股票、基金、觀察、歷史與 AI 私人面板，交易可逐格填表。生活表單內的分類、付款來源及月份使用下拉選單；預算頁可按鈕設定提醒。

`!help` → **生活記帳**，直接開啟生活看板。**＋記一筆消費** 直接開啟單張表單：日期、金額、分類下拉、付款來源下拉、用途，一次填完送出。日期預填今天，使用 `YYYY-MM-DD` 文字欄位，方便直接補登任意日期；「現金／未指定」可直接選，未指定為預設來源。原 `!支出`／`!支出補登` 語法不變，未提供來源記為「未指定」。

預算表單包含月份下拉、分類下拉與金額；固定項目表單包含名稱、金額、分類下拉、「種類與開始月份」合併下拉及期數（分期必填，固定／訂閱留空）。每張表單最多5欄；分類及付款來源下拉直接提供「＋新增分類／＋新增付款來源」。選取並送出原表單會保留草稿、不記帳；按私人新增按鈕填名稱，完成後按「返回原表單」，新項目自動選好，金額、用途與日期保留。表單需先填妥必填欄位才能送出；下拉本身不能直接輸入名稱。超過選單容量可選「其他選項」補選。月份亦可透過「其他月份」補選。

## 啟動（PowerShell）

日常啟動：在專案的 `token.txt` 貼上完整 Bot Token，僅放 Token 本身，不加引號，按 Ctrl+S 儲存。在專案終端輸入 `python bot.py` 即可。關閉終端後此檔案仍保留，不必重新填寫。`token.txt` 已列入 Git 忽略規則，分享專案時仍請排除此檔案。

程式優先使用環境變數 DISCORD_TOKEN，未設定時才讀 token.txt。若之前設定了失效的環境變數，可執行 `Remove-Item Env:DISCORD_TOKEN -ErrorAction SilentlyContinue`，再啟動以改用檔案。

使用 Cursor 選取的有效 Python 執行環境，安裝套件：

```powershell
$env:DISCORD_TOKEN = '填入重新產生的 Bot Token'

```

## 指令

支援一次貼上多行指令，每行一條完整的 `!指令`，依序執行，每則最多 50 行。例如整段傳送：

私訊中連續的生活寫入指令（支出／補登／修改、預算、固定新增／停用、分類新增／停用、提醒設定／重設）會集中回覆各筆結果，減少逐筆等待Discord傳送造成的停頓。遇到投資或其他指令會依原順序分組；每筆仍獨立成功或失敗，不會整批回滾。網路回覆失敗不表示記帳失敗，請先用明細確認，勿整批重貼。

```text
!watch 2330
!watch AAPL
!buy 2330 900 10
!buy 2330 1000 10
```

可保留外層程式碼區塊，空白行會忽略。每行各自執行與回覆；其中一筆失敗不會回滾已成功的交易，修正後只重送失敗的那行，重貼整批會再次記帳。歷史與淨值時間顯示台灣時間 `YYYY-MM-DD HH:MM:SS`，資料庫仍保存 UTC。

- `!help`、`!guide`、`!ping`、`!privacy`
- `!price 2330`
- `!buy 2330 580 10`、`!sell 2330 600 5`（單位：股）
- `!check`、`!remove 2330`
- `!watch 2330`、`!watchlist`、`!unwatch 2330`
- `!fund`、`!fundbuy 台灣50 10000 150`、`!fundsell 台灣50 10 160`、`!fundcheck`
- `!fundprice 台灣50 160`：保存基金淨值與 UTC 更新時間。名稱有空白時用雙引號包住。
- `!portfolio`、`!fundcheck`：直接使用保存的基金淨值，不再等待輸入；缺漏會標記估值不完整。
- `!history` 或 `!history 50`：查看最新交易（上限 100 筆），含已撤銷紀錄。
- `!undo`：預覽最新有效交易；`!undo 編號` 確認撤銷。可依序撤銷，不可跳過較新的有效交易。股票移除也可撤銷。
- `!分析` 或 `!analyze`：先顯示估值，再使用本地模型摘要。
- `!clear yes`：刪除當前使用者的投資資料。

指數指令與行情函式已移除；舊資料庫的 indexes 表未做破壞性刪除，不再使用。

## 計算限制

顯示目前持倉的未實現損益，不含股息、費用與稅。交易歷史自本次更新後開始記錄，日期為記帳時間，無法重建更新前的股票買賣歷史；原持倉保留。基金交易價格不會自動當作最新淨值，需另用 fundprice 更新。撤銷交易不會撤銷淨值更新。不同幣別分開顯示，沒有匯率換算。基金舊資料未記幣別，各基金分開估值。行情為來源提供的最近日線收盤資料，非保證即時成交價；AI 不會自行查新聞或下單。

首次啟動會新增基金淨值與交易歷史資料表，不清除現有資料。`!clear yes` 同時刪除目前使用者的持倉、基金交易、淨值與交易歷史，清除後不可撤銷。更新程式後，先停止舊程序再重新啟動，避免舊版繼續寫入未記錄的交易。
