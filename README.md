**我的資料與隱私**：`更多 → 設定 → 我的資料與隱私` 可查看資料使用說明；匯出、匯入與刪除須在Bot私訊中操作，伺服器頻道不處理這些財務內容或附件。匯出先提醒，再傳送私人附件；空資料仍提供欄位與說明檔，檔案在記憶體產生，不留下專案匯出檔。匯出後仍需另按「確認永久刪除」，取消／逾時不刪除；UI 與 `!生活清除 yes` 共用清除規則，投資及其他使用者資料不受影響。詳細資料範圍、主機與 Discord 可見性限制見 [生活資料與隱私說明](PRIVACY.md)。私人回覆不等於端對端加密，請自行保護下載的匯出檔。

**自行換Discord帳號**：Discord帳號就是帳本身分。舊帳號私訊Bot，從「更多 → 設定 → 我的資料與隱私 → 匯出我的資料」保存新版ZIP；新帳號由同頁「匯入我的備份」上傳。預覽按資料類型列備份、略過與預計新增／套用筆數，明確確認才寫入目前帳號。取消／逾時不寫入；確認時立即交易重新去重，失敗整批回滾，完成列新增／略過／失敗數量。

備份包含消費（含撤銷狀態及已入帳固定／訂閱／分期）、自訂分類、付款來源、常用捷徑，以及本月與未來月份最後儲存的預算設定，不含歷史預算調整。只有本人有投資資料時才附股票持倉、基金交易、觀察清單、基金淨值及必要交易歷史／撤銷關聯。消費以日期、金額、用途、分類、付款來源名稱、來源類型、撤銷狀態與種類完全相同比對，不使用流水號、舊Discord ID或匯出時間；備份內重複也略過。

同名分類／付款來源沿用目前設定（含停用狀態），內建分類視為既有；同名捷徑保留目前設定，完全相同亦略過，新捷徑依備份排序接在既有項目後。目標已有任何預算時略過備份預算；否則套用仍有效的本月／未來預算。投資同股票代號／基金若目標已有持倉、交易歷史或基金淨值，整組略過，避免混合兩份持倉；新標的保留必要撤銷關聯。衝突數列為略過，原帳號資料不刪除。

格式2 ZIP 包含 UTF-8 BOM 的五份CSV（消費、分類、付款來源、捷徑、預算）、README.txt、consumptions.json、settings.json、manifest.json，有投資才附 investments.json。JSON保存原文，CSV文字有公式保護。驗證必要檔案、版本、欄位與SHA-256完整性；**不使用簽章，不能證明來源真偽**，請只使用自己保存的原始檔。格式1及更舊備份不支援，需由舊帳號重新匯出。單次8 MiB、解壓32 MiB，每種資料最多10000筆；超限拒絕、不部分匯入，記憶體處理、不解壓落地。

不搬移舊Discord ID、舊 AI 偏好、Token、管理者設定、其他使用者資料、固定負擔規則、提醒或新手導覽狀態。日常記帳與帳號匯入不再讀寫舊 AI 偏好表；主機整體備份／復原仍按整個 SQLite 快照處理。

**無法登入舊Discord帳號且沒有相容備份時，Bot無法找回資料。** 應用程式不提供管理者查看、搜尋、代匯入、代轉移或個別還原權限；主機管理者仍可能直接讀取本機資料庫。所有財務及資料操作限定Bot私訊，伺服器只保留說明等非財務入口。Discord仍處理附件，私訊不等於端對端加密。使用者換帳號流程不提供刪除帳號、簽章金鑰、多幣別或App帳號。0.10.0的主機每日備份與管理者健康告警另見本機維護說明，不提供個別使用者還原。

**首次使用導覽**：全新使用者開啟生活記帳時，私人導覽卡與主看板一起提供，直接記帳不受阻擋。有消費（含撤銷）、預算、自訂付款來源、捷徑、固定負擔、分類或提醒設定者不會自動顯示；預設現金／未指定不算自訂資料。付款來源與捷徑沿用管理流程，按「返回新手導覽」回同一張卡；當月預算沿用原表單。按「先跳過／完成導覽」永久關閉自動導覽；只關閉訊息而未設定生活資料，下次仍可顯示。手動重新開啟不重設自動狀態；0.9.1起，完整生活清除也會移除導覽偏好，再次開啟視為新使用者。

**手動月結摘要**：`更多 → 洞察 → 本月結帳` 使用看板所選月份，標題為 `YYYY-MM · 月結摘要`。列已記錄總支出、總預算使用／剩餘或超支、前三大分類、依歷史名稱分組的付款來源、未指定來源筆數與金額，以及上月同期差額。本月比較截至今天的共同天數（遇短月取兩邊共同日期），歷史月比較各完整月份，卡片明列比較起訖。任一邊無紀錄顯示資料不足，無總預算顯示尚未設定；空月份仍可看已設定預算。統計沿用有效消費口徑，含有效固定項目並排除撤銷／非消費；資料多時翻頁。僅依已記錄消費統計，不代表全部實際消費。純讀取、不呼叫 AI、不建立排程或推播，全部僅本人可見。

**搜尋帳目**：`!help → 生活記帳 → 帳目 → 帳目工具 → 搜尋帳目`，同一張表單只填名稱／用途關鍵字、開始日、結束日，皆可空白但至少填一項。日期文字欄接受 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`，在共用資料層轉為 `YYYY-MM-DD`；不存在的日期、混用分隔符號、句點及未補零仍拒絕。關鍵字部分比對用途文字，例如「早餐」可找到「早餐店」；與日期條件同時套用。只填開始日查至今天，只填結束日查該日及之前的有效手動消費，兩日期包含起訖日；錯誤格式、未來日期或開始日晚於結束日會拒絕。

搜尋只列自己的有效手動消費，排除固定／訂閱／分期、撤銷及他人資料，依日期與編號由新到舊，每頁6筆。結果顯示日期、金額、分類、用途、付款來源；點選重新讀取紀錄並開既有修改表單，保留所有者、來源／分類驗證與版本衝突防護。搜尋結果與提示僅本人可見；修改後請重新搜尋查看最新結果。

- **帳目管理**：從「帳目 → 月曆」選日查看，或從「帳目 → 帳目工具 → 清單檢視」瀏覽整月，每頁6筆完整資料；選取單筆後以表單修改金額、分類下拉、用途、日期與付款來源下拉。「保留原來源」可保留歷史／停用來源，亦可改選啟用來源。原 `!支出修改` 保留來源，`!記帳撤銷` 可還原；自動固定支出的日期仍不可移動。
- **支出圖表**：從「更多 → 洞察 → 支出圖表」進入，分類分布、付款來源分布、最近六個月趨勢，以Discord原生長條卡片呈現。依看板月份（預設本月），歷史月計整月、本月截至今天；來源依當筆歷史名稱分組，均標明「僅依已記錄資料統計」。空資料有提示，多組資料可翻頁。

僅有效消費計入月報、預算、總覽與圖表。生活功能只記台幣支出，不加入餘額、轉帳、儲值、提款、帳單上傳、銀行串接、匯率或跨幣別總計，亦不推算信用卡未繳金額；無新增依賴、通知內容擷取保存或AI自動入帳。

## 指令

支援一次貼上多行指令，每行一條完整的 `!指令`，依序執行，每則最多 50 行。例如整段傳送：

私訊中連續的生活寫入指令（支出／補登／修改、預算、固定新增／停用、分類新增／停用、提醒設定／重設）會集中回覆各筆結果，減少逐筆等待Discord傳送造成的停頓。遇到投資或其他指令會依原順序分組；每筆仍獨立成功或失敗，不會整批回滾。網路回覆失敗不表示記帳失敗，請先用明細確認，勿整批重貼。

```text
!watch 2330
!watch AAPL
!buy 2330 900 10
!buy 2330 1000 10
```

可保留外層程式碼區塊，空白行會忽略。每行各自執行與回覆；其中一筆失敗不會回滾已成功的交易，修正後只重送失敗的那行，重貼整批會再次記帳。歷史與淨值時間顯示台灣時間 `YYYY-MM-DD HH:MM:SS`，資料庫仍保存 UTC。

- `!help`、`!guide`、`!ping`、`!privacy`
- `!price 2330`
- `!buy 2330 580 10`、`!sell 2330 600 5`（單位：股）
- `!check`、`!remove 2330`
- `!watch 2330`、`!watchlist`、`!unwatch 2330`
- `!fund`、`!fundbuy 台灣50 10000 150`、`!fundsell 台灣50 10 160`、`!fundcheck`
- `!fundprice 台灣50 160`：保存基金淨值與 UTC 更新時間。名稱有空白時用雙引號包住。
- `!portfolio`、`!fundcheck`：直接使用保存的基金淨值，不再等待輸入；缺漏會標記估值不完整。
- `!history` 或 `!history 50`：查看最新交易（上限 100 筆），含已撤銷紀錄。
- `!undo`：預覽最新有效交易；`!undo 編號` 確認撤銷。可依序撤銷，不可跳過較新的有效交易。股票移除也可撤銷。
- `!clear yes`：刪除當前使用者的投資資料。

指數指令與行情函式已移除；舊資料庫的 indexes 表未做破壞性刪除，不再使用。

## 計算限制

顯示目前持倉的未實現損益，不含股息、費用與稅。交易歷史自本次更新後開始記錄，日期為記帳時間，無法重建更新前的股票買賣歷史；原持倉保留。基金交易價格不會自動當作最新淨值，需另用 fundprice 更新。撤銷交易不會撤銷淨值更新。不同幣別分開顯示，沒有匯率換算。基金舊資料未記幣別，各基金分開估值。行情為來源提供的最近日線收盤資料，非保證即時成交價；Bot 不會自行查新聞或下單。

首次啟動會新增基金淨值與交易歷史資料表，不清除現有資料。`!clear yes` 同時刪除目前使用者的持倉、基金交易、淨值與交易歷史，清除後不可撤銷。更新程式後，先停止舊程序再重新啟動，避免舊版繼續寫入未記錄的交易。

### localhost Web v1

未登入首頁仍只顯示Discord OAuth登入。登入後首頁可直接新增一筆本人的生活消費：分類與付款方式只取自目前登入使用者，日期預設台灣今天，成功後重新導向提示頁以避免重新整理重複寫入。搜尋與設定入口位於表單上方；表單下方的「本月預算」顯示已記錄支出、整數總預算及兩位小數的剩餘／超支金額，皆附「元」。沒有總預算時顯示「尚未設定總預算」及設定入口，不會把分類預算自動當成總額。

首頁「小月曆」以Monday-first七欄顯示台灣本月，日期格只顯示日期與有效消費記號。今天與過去日期可點進既有當日明細；未來日期仍保留格子但不連結，完整月曆也採相同規則。「查看完整月曆」可瀏覽本月與過去月份，選日後才顯示合計、用途、分類及付款方式。摘要和記號包含本人已入帳、有效且未撤銷的生活消費（含固定、訂閱、分期），首頁不會同步尚未入帳的固定規則。資訊卡讀取失敗只顯示固定安全訊息，保留快速記帳與錯誤草稿。

首頁每次呈現重用月份摘要與月曆Service各一次；兩個讀取不共用交易快照，Bot同時寫入時可刷新更新。既有付款方式讀取仍可能補建本人「現金／未指定」，即使已存在也可能推進SQLite自動編號計數，因此整個首頁請求不能稱為完全唯讀。本輪未修改核心、Service、資料庫結構或依賴。

首頁的「搜尋帳目」提供消費項目關鍵字、開始日期與結束日期。空白初始頁不查詢；至少需填關鍵字或開始日期，開始日期未填結束日期時查到台灣今天，關鍵字可搭配結束日期查詢較早記錄。結果只顯示日期、金額、消費項目、分類及付款方式；無結果與不合法條件使用固定安全訊息。此頁是唯讀GET，不提供排序、分頁、分類／付款方式篩選、編輯、撤銷、刪除或匯出。

首頁的「設定」提供台灣本月總預算、分類預算、分類與付款方式管理。總預算與分類預算可分別設定、修改或清除；沒有總預算時仍可設定分類預算，有總預算時不得低於分類預算合計，也可用「設為分類預算加總」一次設定最低總額。分類可新增、改名與停用；停用不刪除歷史資料。付款方式可新增、改名與停用，但「現金」與「未指定」維持不可改名或停用。此版不提供月份切換、固定支出、捷徑或提醒管理。

Web路由不接受外部指定的 `user_id`，也不直接存取SQLite；資料只沿 `web route → session Discord user_id → life_ledger_service.py → spending.py → SQLite` 讀寫。所有設定寫入使用既有CSRF與POST／Redirect／GET流程。

在專案根目錄自行建立不提交的 `.env`，設定下列變數：

- `WEB_SESSION_SECRET`
- `DISCORD_CLIENT_ID`
- `DISCORD_CLIENT_SECRET`
- `DISCORD_REDIRECT_URI`

`WEB_SESSION_SECRET`必須是至少32字元的非範例值。Discord Developer Portal必須登錄完全相同的回呼網址：`http://127.0.0.1:8000/auth/discord/callback`。專案只讀根目錄的 `.env`；此檔案已被Git忽略，不可上傳或填入 `.env.example`。

若從本worktree啟動Web，請在同一個PowerShell視窗以 `DISCORDBOT_DB_PATH` 明確指定既有Bot帳本。此變數只在目前PowerShell視窗有效，關閉視窗後需重新設定；只接受絕對路徑，相對路徑會以固定錯誤拒絕。路徑不應加入Git、範例設定檔或公開貼文。

請依下列安全順序操作；第2步會更新資料庫結構，**必須先自行備份既有帳本**。Web啟動本身不會呼叫 `db.init_db()`：

# 2. 使用者先自行備份該檔案後，才執行一次 schema 初始化

# 3. 以相同 PowerShell 視窗啟動網站
& '.venv\Scripts\python.exe' -m uvicorn web.app:create_app --factory --host 127.0.0.1 --port 8000
